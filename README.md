# Shahil Gautam — React Portfolio

Responsive dark/blue portfolio built with React + Vite.

## Run in VS Code

Open the `shahil-portfolio` folder in VS Code, then run:

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Project structure

```text
shahil-portfolio/
├── public/
│   ├── profile.png
│   └── resume.pdf
├── src/
│   ├── main.jsx
│   ├── styles.css
│   └── hero-reference.png
├── index.html
├── package.json
└── README.md
```

## Customize

- `public/profile.png` — hero portrait
- `public/resume.pdf` — downloadable resume
- `src/main.jsx` — name, links, projects, skills and contact details
- `src/styles.css` — design and responsive layout

## Important

Do not commit `node_modules/`. Run `npm install` after extracting/cloning the project.

Before publishing, replace placeholder GitHub/LinkedIn links with your real profile URLs.
